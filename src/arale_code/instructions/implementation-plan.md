# Implementation Plan

## Preconditions

The development environment MUST use Python 3.12 and the declared package manager. All required dependencies MUST be locked prior to execution.

## Ordered tasks

Implementation tasks MUST proceed in sequential order without skipping verification steps:
1. Establish baseline and package structure.
2. Validate and bundle instruction assets.
3. Implement the content catalog.
4. Expose protocol surfaces.
5. Verify standard input and output transport.

## Validation gates

Every phase MUST satisfy all defined exit criteria before subsequent work begins. Automated tests MUST pass completely without network access.

## Completion report

The final delivery MUST report all modified files, validation results, and residual risks.
